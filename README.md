# Mushroom Quest — Android RPG

A native Android 2D mushroom-themed RPG prototype.

Features:
- Tap-to-attack battles and stage progression
- Enemy HP and increasing difficulty
- XP, level-ups, gold rewards and permanent power upgrades
- Three weapon selections and three pet companions
- Local save data using Android SharedPreferences

Build:
GitHub Actions builds a debug APK on every push to main or manual workflow dispatch.
Open Actions → Build Android APK, then download the MushroomQuest-debug-apk artifact.

This is an original genre-inspired prototype, not a copy of the commercial game's assets or source.
